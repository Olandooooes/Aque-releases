# 净像工坊（Aque）官方发布

这里用于保存净像工坊 Windows 官方安装包、SHA-256 校验文件和历史版本。

- 官网：[aque.xingo.fun](https://aque.xingo.fun)
- 最新版本：[GitHub Releases](https://github.com/Olandooooes/Aque-releases/releases/latest)
- 问题反馈：[GitHub Issues](https://github.com/Olandooooes/Aque-releases/issues)

## 安全下载

请只从官网或本仓库 Releases 下载。每个正式版本均包含：

- `JingXiangStudio-版本号.exe`
- `JingXiangStudio-版本号.exe.sha256`

你可以在 PowerShell 中校验安装包：

```powershell
Get-FileHash .\JingXiangStudio-1.0.0.exe -Algorithm SHA256
```

## 使用范围

净像工坊用于处理用户自己拥有、创作或已获授权的图片。请勿用于移除无权处理的版权声明、规避付费授权或侵犯第三方权益。
